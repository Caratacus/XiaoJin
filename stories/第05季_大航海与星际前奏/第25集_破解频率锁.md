# 第25集_破解频率锁

**前情回顾**：从那天起，小金他们没有急着下洞，而是沿着停下来的挖掘机轨迹一段段丈量、比对。他们确认：那些沟槽和车辙并不是乱挖，而是一条被反复修整过的正式运输线，通往欧米伽系统正在向地下扩张的网络。小金把通道走向、沟槽数量和挖掘顺序全记进笔记，决定带着这些判断，真正走进那条红光里的入口。

---
小金和他的伙伴们站在挖掘机的铲斗下方，抬头望着这个庞然大物。就在几分钟前，它还在疯狂地工作着，破坏着周围的微小生命。现在，它安静地停在原地，像是一个沉睡的钢铁巨人。

“我们真的要进去吗？”小彩有些紧张地看着那个透着红光的洞穴。

“我们必须进去。”小金坚定地说，“那里可能藏着关于欧米伽系统的重要信息。”

他率先踏入了洞穴，伙伴们紧随其后。

洞穴内部比他们想象的要宽敞得多。这里似乎是一条人工开凿的通道，墙壁上布满了机械管道和电缆。那些电缆散发着微弱的蓝光，为这条幽暗的通道提供着照明。

“这里应该是欧米伽系统挖掘的运输通道。”独眼警卫分析道，“它用这台挖掘机来连接不同的地下设施。”

他们沿着通道前进，越走越深。周围的温度逐渐升高，空气中弥漫着一种金属受热后的特殊气味。

“等等。”小金突然停下脚步，“你们听到了吗？”

“听到什么？”小彩有些疑惑。

“一种……嗡嗡声。”小金侧耳倾听，“很轻，但是很有规律。”

独眼警卫的独眼快速闪烁了几下。

“我的传感器也检测到了。”它说，“是某种小型飞行器的声音。而且……不止一只。”

话音刚落，前方的通道突然亮了起来。数十个只有拳头大小的飞行器从阴影中飞了出来。它们有着圆形的机身，下方挂着小小的机械爪，身上闪烁着红色的指示灯。

“是清理微型无人机！”独眼警卫大声警告，“它们是用来清理入侵者的！”

“保护小金！”黑焰立刻挡在小金身前，双手燃起黑色的火焰。

那些无人机并没有直接攻击，而是开始在四周飞舞，似乎在等待着什么。

“它们……它们好像在等我们做什么。”小彩有些疑惑。

“不。”小金仔细观察着那些无人机，“它们是在等待某种指令。或者说，它们是在等待我们触发某个机关。”

他向前走了几步，发现通道的前方被一道巨大的金属门挡住了。那扇门上有一个复杂的控制面板，上面闪烁着各种符号和灯光。

“那是一道安全门。”独眼警卫说，“旧标牌把它叫作‘三通道频率锁’，但这个名字容易误解。它实际核验的是三种传感通道，不是把热、光和生命硬分成低中高频。”

小金走到那扇门前，仔细观察着控制面板。那上面没有按钮，没有开关，只有一个圆形的传感器和一个频率刻度盘，刻度从最低到最高画着七条长短不一的线。

“第一条是温度校准，第二条是光学编码，第三条是带身份信息的生命样本确认。”独眼警卫说，“三条同时通过，门才会开。”

“怎么匹配？”小金问。

“每条通道都有允许范围，不能多，不能少，也不能冒充。”独眼警卫扫过控制面板，“温度板需要稳定热源；光学孔需要按刻度依次输入七种颜色；身份槽则需要活体反应和我的维修权限码同时出现。”

小金脑中快速整理了一遍——稳定热源来自黑焰，七色光序列来自小彩，活体反应与权限码则要金色植物和独眼警卫配合。

“黑焰，你负责温度板。”小金转过身，“不需要爆发，只要像温热食物时那样，把温度稳定在绿色刻度里。”

“小彩，你负责光学孔。”小金看向弟弟，“按面板给出的顺序送入七种颜色，每次等指示灯确认后再换下一种。”

“那你呢？”小彩问。

“身份槽——”小金走到花盆旁，小心翼翼地将金色植物放在传感器旁边，“它只能证明这里有活体。独眼警卫，你再发送自己的维修权限码。两项必须分别通过，不能混成一种信号。”

“明白。”独眼警卫站到金色植物另一侧，伸出一根手指对准感应区。

“准备好了吗？”小金看了看所有人。

黑焰点了点头，单手贴在控制面板下端的导热板上。他闭上眼睛，掌心没有冒出火苗，只让导热板表面平稳升温。温度指针缓缓移动，停在绿色区域内。

“温度通道通过。”小金说，“小彩，轮到你了。”

小彩深吸一口气，伸出手指。七彩光芒在指尖凝聚成一根细线。他按红、橙、黄、绿、蓝、靛、紫的顺序逐一照入圆孔，每换一种颜色都等面板回闪一次。第七次回闪后，光学通道亮起绿色。

“还有身份通道。”小金看向金色植物和独眼警卫。

金色植物的叶片微微张开，传感器先确认了稳定的生命反应。紧接着，独眼警卫将指尖搭在面板边缘，发送维修权限码。两项结果分成两行显示，身份通道的红色警告灯闪烁了几秒……

然后也变成了绿色。

三个传感通道的指示灯全部亮起时，那扇巨大金属门发出一声低沉的闷响，缓缓向两侧滑开了。

“我们成功了！”小彩兴奋地欢呼。

但就在这时，那些一直在空中盘旋的清理无人机突然改变了模式。它们的红色指示灯变成了危险的闪烁频率，开始向众人俯冲下来。

“它们被激活了！”黑焰大声警告，“谜题被解开的同时，也触发了防御系统！”

“保护记忆孢子！”小金大喊，“小彩，黑焰，阻挡它们！”

小彩立刻爆发出七彩的能量，形成一道防护屏障。可屏障刚撑起来，他就明显感觉到今天的火焰比在高塔时更难稳定——边缘一阵一阵发虚，像被通道里细密的电流声不断削薄。黑焰则双手燃起黑色的火焰，准备迎击那些俯冲而来的无人机。

但那些无人机的数量太多了。它们像一群愤怒的蜜蜂一样向众人扑来，有的试图突破小彩的屏障，有的绕到侧翼发起攻击。

“太多了！”小彩咬着牙坚持着，“我挡不住所有的！”

“我们不需要挡住所有的。”小金冷静地说，“我们只需要争取时间，找到主控开关！”

他冲向通道深处，那里应该有一个控制这些无人机的中央系统。

“独眼警卫，帮我找到无人机的控制核心！”小金大声喊道。

“正在扫描！”独眼警卫的独眼快速闪烁，“找到了！就在前方五十米处的那个控制箱！”

小金向着那个控制箱冲去。几架无人机试图拦截他，但黑焰及时赶到，用黑色火焰将它们击退。

“继续前进，小金！”黑焰大声喊道，“我会挡住它们！”

小金冲到那个控制箱前，迅速打开面板。里面是一个复杂的电路系统，无数条线路交织在一起，就像是一个迷宫。

“这里没有简单的开关。”小金快速观察着，“我需要找到正确的切断点。”

“小金，听我说。”独眼警卫的声音从通讯器里传来，“控制箱里有维修用的紧急停机回路。无线主信号不能随便剪断，否则无人机可能启动各自的失联保护程序。你要找带黄色条纹的双线接口，同时断开两端，才能让它们安全降落。”

“紧急停机接口在哪里？”

“在电路板右下角。”独眼警卫指导道，“先确认两条黄线都接到同一个安全继电器，不能碰旁边的红色供电线。”

小金找到了那只安全继电器。两条黄线从它两侧伸出，旁边的红线仍在发亮。

*就是这里……* 小金在心中默默想道。*必须让停机指令完整闭合，不能只剪断一根线。*

他从背包里掏出一把小剪刀——那是由坚韧的蛛丝和金属碎片制成的工具。

“对不起，小家伙们。”小金对着那些无人机轻声说道，“你们也只是按照程序在执行任务。但你们不能伤害我的朋友。”

他用绝缘夹同时松开两条黄色接口，又把它们扣进紧急停机槽。

轰——

所有无人机先减慢螺旋桨，再一架一架降到地面。红色指示灯熄灭，只剩黄色待机灯规律闪烁。

“成功了！”小彩欢呼道。

“紧急停机生效了。”独眼警卫解释道，“它们保留巡航记录，但攻击和远程接管暂时被维修锁隔离。只要锁还在，就不会伤害我们。”

小金长舒一口气，靠在控制箱上，感觉全身的力气都被抽干了。

*我们又一次做到了……* 他在心中默默想道。*不是通过暴力，而是通过智慧。*

“小金，你没事吧？”小彩跑过来，关切地问道。

“我没事。”小金微笑着站直身体，“只是有点累。”

他望向通道的深处，那里仍然透着诡异的红光。

*前哨站……欧米伽系统……* 小金在心中默默想道。*我们越来越接近真相了。*

“我们继续前进。”小金做出决定，“前哨站就在前面。”

独眼警卫只重新启用其中三架的低速巡检功能，并保持维修锁生效。三架无人机静静地跟在后面，其余的留在原地待机。

而在通道的尽头，一个更加庞大的地下设施正在等待着他们——欧米伽系统的前哨站，那个隐藏着无数秘密的地方。

**互动时刻**：

1. **自我调节**：面对突然出现的清理无人机，小金没有惊慌，而是冷静地找到了控制核心并切断了信号源。当你遇到突发危险时，你能像小金一样快速找到问题的根源吗？
2. **换位思考**：那些清理无人机只是在按照程序执行任务，当小金切断信号源时，它们变得安静下来。想象一下，如果你是那些无人机，当你突然被“唤醒”，发现自己在攻击无辜的人，你会有什么感觉？
3. **智慧与宽容**：故事中的电磁锁需要匹配三种不同频率段的能量——低频、中频、高频。团队里每个人的能力不同，正好对应了不同的频段。你知道为什么有些锁需要多种"钥匙"同时使用才能打开吗？团队合作和频率匹配有什么相似之处？
4. **悬念预测**：小金他们成功解开了三道频率匹配锁，还重置了那些清理无人机。现在无人机们安静地跟在他们后面。你觉得这些无人机接下来会帮助他们吗？前哨站里会有什么呢？
