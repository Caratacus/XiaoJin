# 第06集_漂在水上的伤痕图

在上一集中，露珠动力号穿过了一座由人类废弃塑料堆成的恐怖"大陆"。小彩用精密的微热线切断了缠绕在蒸气管口的渔网丝，露珠动力号才侥幸脱困。穿过塑料大陆后，水面上的漂浮物变少了，空气也稍微干净了一些，但小金看着身后那片五彩斑斓的废墟，心里并不觉得轻松。远方传来的低频震动还在继续，像某种巨大机器的心跳。他隐约觉得，这一路上看到的脏东西并不是各自独立的，它们之间也许藏着某种还没有看懂的规律。

小金在船尾蹲了下来，把叶片笔记摊开在膝盖上。

露珠动力号正缓缓驶过一段相对平静的水面。两边还能看到零星的塑料碎片和油渍，但已经不像塑料大陆中心那样密不透风了。黑焰把动力炉降到了最低档，让船慢慢滑行，节省热石的能量。

"我们停一停。"小金忽然说。

"停？"小彩从船头转过头来，"可是刚刚才逃出来，不是应该趁热打铁往前赶吗？"

"正因为刚刚才逃出来，"小金抬起头看着弟弟，"所以现在是我们看得最清楚的时候。再往前走一段，那些刚才差点吞掉我们的东西就会变成远处一个模糊的影子。趁它们还在目视距离以内，我要把见过的每一样都画下来。"

小彩张了张嘴，似乎想反驳，但看到哥哥已经开始在叶片上画图了，便把话咽了回去。

小金先画了一幅从出发到现在的大致路线图。从玉米粒王国的水塘出发，经过七号浮标，进入迷雾水域，遇到变异水虫，再穿过塑料大陆——他用不同颜色的浆果汁标注了每个区段的水质状况：出发时是浅绿色，迷雾水域变成了深灰色，塑料大陆那段则被他涂成了刺眼的紫红色。

"小翠，你现在帮我数一下，从迷雾水域开始到现在，水面上能看到多少种不同的漂浮物。"小金头也不抬地说。

小翠从船舷边直起身，手里那片滤材还没放下。她想了想，开始一个一个地报："黑色油膜、蓝色化学结块、灰白色工业废胶、透明塑料薄膜、彩色瓶盖碎片、渔网丝、白色泡沫块、黑色焦油团……还有，刚才在水虫背上洗掉的那种沥青一样的黏稠物。"

"九种。"小金在路线图旁边列出一张表，每一行写上漂浮物的名称、第一次出现的地点和大致数量。

"等等，还有。"小翠补充道，"这些漂浮物不是均匀散开的。你注意到了吗？迷雾水域那一带，以黑色油膜和蓝色化学结块为主；到了塑料大陆附近，几乎全是塑料和渔网；而现在这一段——"她指了指船边的水面，"泡沫块和焦油团开始变多了。"

小金手中的笔停了下来。他抬起头，重新审视自己的路线图和漂浮物列表。

*每一段水域有自己的"主要垃圾"。它们不是随便混在一起的，而是按照类型在各自的区域扎堆。*

"黑焰，你出来看一下。"小金朝底舱喊道。

黑焰爬出来，身上还带着热石散发的温暖气息。小金把路线图递给他。

"你看这些漂浮物的分布。"小金指着列表说，"化学废料集中在迷雾水域，塑料集中在大陆区域，焦油和泡沫开始出现在我们现在的位置。你觉得这说明什么？"

黑焰接过叶片，认真看了好一会儿。他的目光从列表移到路线图上，又从路线图移回列表，眉心慢慢拧了起来。

"不同种类的东西，是从不同的口子排出来的。"黑焰低声说，"就像我后厨的排水槽一样——洗菜的水、洗锅的水、倒油的水，味道和颜色都不一样。如果它们混在一起，那就是一团混沌；可如果它们各有各的地盘，说明上游有不同的管子在分别排放。"

"对。"小金点了点头，"而且这些'管子'的排放方向也不一样。你看——"他用笔尖从南方的方向划了几条线，"化学废料集中在西边水域，塑料集中在东边堆积带，焦油和泡沫开始往中间汇合。如果我在地图上把它们画成箭头……"

他在叶片上画出三条不同颜色的线：西边一条蓝色线（化学废料），东边一条绿色线（塑料），中间一条黑色线（焦油泡沫）。三条线像河流的支流一样，从南方汇聚过来，在露珠动力号经过的水域交汇成一片脏水混合区。

"这是一张伤痕图。"小金看着自己画出的线条，声音变得很轻。

"伤痕？"小彩凑过来看。

"嗯。你想想看——如果一个人身上有三道伤口，分别在不同的地方，你是觉得他分别被碰了三次，还是觉得有一只手同时划了他三道？"

小彩的嘴巴张成了一个圆："你是说，这些不同的污染……是同一个东西制造出来的？"

"不是同一个东西，而是同一套系统。"小金纠正道，"上游有什么东西——可能是一座工厂，也可能是好几座——它们像章鱼的触手一样，从不同的方向往水里排污。化学废料走西边，塑料垃圾走东边，焦油泡沫走中间。每一条都像是单独的脏水沟，可它们的源头，都指向同一个方向。"

他用笔尖点了点路线图的最南端，那里被他画了一个大大的问号。

小玉一直安静地坐在桅杆旁听他们分析，手里的笔记翻开着，却没有动笔。她看着小金画出的那张伤痕图，目光里带着一种安静的欣慰。

"这张图画得好。"小玉终于开口，声音比平时慢了一些，"它让我想起古籍里的一句话——'水面上的伤痕会说话，只要你愿意把它们连起来听。'你今天做的事情，就是在让伤痕说话。"

小金把这张伤痕图小心地从笔记本上撕下来，用干净的叶片夹好，放进背包最安全的夹层里。

"我有一个想法。"他站起身，环顾四周的水面，"从现在开始，每经过一个新的水域，小翠负责采水样和记录水质变化，黑焰负责监测水温和蒸气管状态，小彩负责掌舵和观察左右两侧。你们看到任何不正常的东西——哪怕只是一块颜色奇怪的小碎片——都要第一时间告诉我。"

"那船长哥哥你呢？"小彩问。

"我把你们看到的所有东西，都画进这张伤痕图里。"小金拍了拍背包，"等我们走到污染源头的位置，这张图就会变成完整的证据。到那时候，我们就不是在说'外面很脏'了，而是能清清楚楚地告诉大家，脏东西从哪来、怎么来的、一路毁掉了什么。"

小彩愣了一下，然后使劲点头："我懂了。就像你写航海手册一样——不只是记发生过什么，还要让后来的人能看懂为什么发生。"

"对。"小金微笑着拍了拍弟弟的肩膀，"这就是知识最厉害的地方。不是让你变聪明，而是让你变成能把看到的东西讲清楚的人。"

远方的低频震动又传来了，这一次比之前更清晰，像有人在很深很深的地底敲鼓。小金在伤痕图的南端又补了一个记号，然后在旁边写了三个字："震源区。"

*我们离源头越来越近了。* 他望着南方灰蒙蒙的天际线，握紧了手中的笔。*而这张图上的每一道伤痕，都在告诉我，那里有什么东西在等着被看见。*

---

**互动时刻**：

1. **自我调节：** 小金没有因为刚刚脱险就急着往前赶路，而是停下来把沿途看到的污染记录清楚。当你经历了一件很紧张的事情之后，你会立刻冲向下一段，还是会像小金一样先缓一缓、想一想，把刚才的经历变成经验？

2. **换位思考：** 黑焰用"后厨排水槽"的比喻来理解污染分布——洗菜的水、洗锅的水、倒油的水各有各的味道和去处。你能想到生活中有什么类似的情况吗？不同的垃圾是不是也应该分开处理？

3. **智慧与宽容：** 小金把零散的漂浮物画成了一张完整的"伤痕图"，让大家一眼就能看懂污染的规律。你觉得"把碎片拼成完整的画面"这种能力，在生活中还有什么用处？

4. **悬念预测：** 小金在伤痕图的南端标注了"震源区"，远方的低频震动越来越清晰。你觉得那片震源区里会有什么？是一座巨大的工厂，还是某种他们从未见过的机器系统？
