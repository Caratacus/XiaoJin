# 第06集_小玉的第一次独立行动

**前情回顾**：小金去荒草地看望地鼠一家时，意外得知西边野花甸的地下可能有异常。回来后他告诉了小玉，两人决定第二天一起去查看。可那天晚上，小金在广场和玉米王讨论明天的行动路线，小玉独自留在实验室整理前几天从荒草地带回来的泥土标本。就在她以为今晚只是普通的加班时，却先撞上了另一件怪事。

---

小金说过，明天一早去野花甸。可那天傍晚，小玉没有早早回去休息，而是独自留在实验室里，把前几天从荒草地带回来的泥土样本重新分类。

她戴着那副透明树脂老花镜，坐在玉米秆架子前，用小金做的放大镜一颗一颗地检查土样里的杂质。萤火虫灯笼挂在头顶，暖黄色的光把整间实验室照得亮堂堂的。

就在她把第三瓶土样倒进浅盘时，眼角余光扫到了一个奇怪的现象。

实验室门口的台阶下面，蚂蚁工程师们正在搬运东西。这不奇怪——自从上次帮小金堵了地鼠隧道，蚂蚁们就养成了每天傍晚巡查实验室周边的习惯。可今晚的队伍不太一样：它们没有走平时那条沿墙根的路线，而是全都绕了一个大弯，刻意避开了台阶东侧的一小块地方。

“它们在绕路。”小玉放下放大镜，自言自语道。

她没有立刻去叫小金。因为小金今晚在广场和玉米王讨论明天的行动路线，而且她心里冒出了一种奇怪的预感：如果每次都等小金来判断，自己就永远只能在旁边递东西。

小玉站起来，走到台阶旁蹲下。绕路的蚂蚁们经过她脚边时，触角都在微微颤抖，像是闻到了什么让它们不安的气味。她顺着蚂蚁绕行的方向往东侧看去——台阶下面的泥土颜色比周围深了一层，湿漉漉的，用手指一按就陷下去一个小坑。

“地下有水。”小玉皱起眉头。

她又凑近闻了闻，潮湿的泥土里混着一丝酸涩的味道，不像普通的雨水，倒像地底深处涌上来的旧水。小玉想起了小金早期观察札记里的一句话：“泥土如果在不该湿的时候变湿，要么是上面漏了，要么是下面涌了。”

她找了一根细玉米秆，小心地往潮湿的地方插下去。玉米秆刚插进两指深，就碰到了一个软软的空洞——地下有一段隧道，而且隧道壁已经泡软了。

小玉的心跳加快了一点。她知道这段隧道的位置：它是蚂蚁工程师们用来连接实验室东墙和主巢穴的辅道，平时用来运送材料和传递消息。如果隧道塌了，不仅蚂蚁的交通会中断，实验室东墙的地基也会跟着松动。

“不能等明天了。”小玉对自己说。

她没有慌张。她攥了攥拳头，让自己冷静下来，然后回到实验室，从架子上取下两样东西：一小瓶蜘蛛丝胶——这是小金之前用蜘蛛丝和晨露调配的黏合剂，干了以后比石头还硬——还有一卷细铜丝，是从人类废弃的电线里抽出来的。

然后她做了一件让蚂蚁们大吃一惊的事：她对着蚂蚁队伍喊了一声。

“蚂蚁队长！我有事找你们！”

蚂蚁们停了下来。队长从队伍里走出来，触角疑惑地晃了晃。

“你们绕路是因为东墙下面的隧道进水了，对吗？”小玉问。

蚂蚁队长的触角猛地一抖——它没想到这个戴眼镜的玉米粒女孩居然看出来了。

“是的，”蚂蚁队长压低声音说，“三天前开始渗水，我们用黏土球堵了两次，可水还是从更深的地方渗上来。我们不想打扰小金长老，他明天有重要的事……”

“我知道，”小玉点点头，“所以我来帮你们。”

蚂蚁队长犹豫了一下。在它的印象里，小玉一直是那个站在小金旁边递东西、记笔记的人。可今晚她的眼神不太一样——不是在等谁来告诉她该怎么做，而是已经准备好了自己动手。

“你确定？”蚂蚁队长问，“渗水的地方在隧道最深处，路不好走。”

“我走得动，”小玉拍了拍膝盖上的土，“而且我比你们高，能看到你们看不到的东西。”

她跟着蚂蚁队长来到东墙根下。果然，一小股细细的水流正从地底渗出来，把隧道壁泡得又软又滑。如果再泡一天，整段隧道就会塌陷。

小玉蹲下来，仔细观察水流的方向和速度。水不是从上面来的——台阶上方没有漏水的痕迹。它从更深的地底往上冒，像是地下某处有一条暗流改了道。

“堵是堵不住的，”小玉说，“得把水引走。”

她用细铜丝弯了一个小小的导流槽，插在渗水点的下方，让水流顺着铜丝滑到旁边一个更低的凹坑里——那里刚好有一个蚂蚁们废弃的小洞穴，可以当临时蓄水池。

接着，她把蜘蛛丝胶涂在隧道壁被泡软的地方，又让蚂蚁们搬来干土和碎玉米壳，一层层糊在胶水外面。蜘蛛丝胶很快凝固了，把软化的隧道壁重新加固成硬邦邦的壳。

“这样水就不会继续泡墙了，”小玉站起来，拍了拍手上的土，“但你们要每天检查蓄水池，满了就清空。等小金回来，我让他看看能不能找到水源，从根上解决。”

蚂蚁队长看着那个小小的导流槽和加固后的隧道壁，触角弯了弯——那是蚂蚁表达最高敬意的方式。

“小玉姐姐，”它说，“你比我们想的厉害多了。”

小玉笑了笑，没有多说什么。她只是回到实验室，在公用观察簿的空白页上写下一段话：“东墙隧道渗水——三天前开始，水源在更深处。临时方案：铜丝导流槽引至废弃洞穴，蜘蛛丝胶加固隧道壁。需长期观察。”写完后，她想了想，又在最后加了一行小字：“第一次自己发现问题、自己想办法。感觉还不错。”

她合上笔记本，走到窗边，看了看天上的月亮。月亮还没完全圆，可银色的光已经很亮了，把实验室门口那条小路照得清清楚楚。她忽然想起小金说过的一句话：“观察不只是用放大镜看，还得用耳朵听、用鼻子闻、用心去感觉。”今晚她就是用眼睛“感觉”到了蚂蚁的异常——它们绕路的样子，像一条被风吹歪的线，一看就知道不对劲。

小玉又坐回桌前，翻开那本还没读完的《月神传说集》。书页在萤火虫灯笼的光里泛着淡淡的黄，像被时间泡过的老玉米皮。她读了几页，眼皮开始发沉，可心里却很踏实——因为她终于知道，自己不只是那个“递东西的人”。

那天深夜，小金从广场回来时，发现实验室东墙根下的蚂蚁队伍恢复了正常的路线。他蹲下来看了看，发现了铜丝导流槽和加固过的隧道壁。

“这是谁做的？”他惊讶地问。

蚂蚁队长指了指实验室里还在灯下看书的小玉。

小金走进实验室，看着桌上那段弯成弧形的铜丝和那瓶用了一半的蜘蛛丝胶，再看看小玉笔记本上工工整整的记录，忽然笑了。他翻了翻那页记录，从渗水的时间、位置、水流速度，到导流槽的角度和加固材料的配比，每一条都写得清清楚楚，比他自己写的某些记录还详细。

“小玉，”他说，“你不用等我回来的。”

小玉推了推老花镜，嘴角微微弯起：“我知道。我只是想试试看。没想到真的管用。”

那天晚上，小金在公用观察簿里翻到小玉写的那段记录时，认认真真地在旁边补了一句：“小玉独立处理东墙隧道渗水——方案合理，记录完整。以后实验室的事，可以多问问她。”

而小玉不知道的是，第二天一早，小金在出门去野花甸之前，还特地把蚂蚁队长拉到一边，低声说了一句：“以后有什么事，也可以先找小玉。她看得见别人看不见的东西。”

**互动时刻**：

1. **自我调节**：小玉发现蚂蚁绕路时没有慌张，而是先观察再行动。你在发现异常情况时，会先观察还是先着急？
2. **换位思考**：蚂蚁队长不想打扰小金，所以一直自己想办法堵水。如果你有困难但不想麻烦别人，你会怎么做？
3. **智慧与宽容**：小玉没有用水泥封死隧道，而是用导流槽把水引走。你觉得“堵”和“疏”哪个更好？为什么？
4. **悬念预测**：小金和小玉明天要去野花甸查看异常，你觉得他们会在那里发现什么？
