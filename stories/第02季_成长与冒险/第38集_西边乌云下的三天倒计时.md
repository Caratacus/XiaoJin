# 第38集_西边乌云下的三天倒计时

**前情回顾**：彩虹桥修复了。七色宝石归位，七彩光芒重新照亮了东边的天空。可喜悦还没完全散开，红隼就从高空带回了更坏的消息——西边的黑烟不是错觉，那里的势力正在集结。而小玉从古籍中翻出的记载，让"三天之后"这句倒计时有了真正的重量。于是，庆祝刚结束，整个王国就被迫从寻找宝石的冒险节奏，切进了守望与准备的三日时刻。

---
**彩虹桥亮了**

七色宝石全部归位的那一刻，彩虹桥发出了震耳欲聋的光芒。

七种颜色在天空交汇，像一条巨大的缎带横贯东西。桥的东端连接着小玉米粒王国，光芒温暖明亮；桥的另一端本应延伸到远方，但——

“桥到一半就断了。”小金站在山顶，看着彩虹桥在西边的半空中戛然而止。

北边那条被七彩光斑引出来的路，他们一路走到了这里，本以为下一步会继续朝着更远的水声去。可现在，先拦在门口的却不是北方的新谜题，而是西边已经逼近的阴影。

那一端不是自然的终点，而是被什么东西截断了。断口处的七彩光芒像是遇到了一堵无形的墙，在那里扭曲、消散，最后变成几缕可怜的光丝被黑暗吞没。

"修好了，但没完全修好。"紫晶国王叹了口气。

小金没有叹气。他把目光从彩虹桥的断口移向西边更远的天际线——那里，一层灰蒙蒙的烟雾像一道幕布，把天空的西半边遮得严严实实。

"那是……"小彩指着那层灰幕，七彩光芒不自觉地亮了起来。

"是红隼之前看到的那堵灰烬之墙。"小金的语气很平静，但握紧了拳头。

**红隼的紧急报告**

就在大家还沉浸在彩虹桥的震撼中时，红隼从高空俯冲下来，速度比以往任何一次都快。它的翅膀还没收拢就开始说话，声音急促而严肃：

"小金，西边——变了。"

红隼难得地停顿了一下，像是在组织语言描述一种它无法理解的东西。

"灰烬之墙还在，但墙后面多了一些东西——很多黑色的点在移动，密密麻麻，像蚂蚁搬家一样整齐。有方形的东西——可能是车或者箱子。还有火光，不是灶火做饭的那种小火，是……一排一排的大火。"

"它们在往东边走吗？"小金追问。

"暂时没有。但它们在集结，像是……在等什么信号。"

小金打开笔记本，翻到之前记下的那张碎纸片和旧册子的记录。三组关键词在脑海中碰撞：

"西方荒地"——红隼已经确认存在。
"大锅"——红隼看到的一排一排的大火。
"三天之后"——集结。

他看向小玉顾问。

**古籍里的记载**

小玉已经在翻阅古籍了。这一次她翻得很深，翻过了所有常见的篇章，一直翻到书页最薄、字迹最淡的最后几页。

"找到了，"她的声音低沉但清晰，"'西荒之民，以黑焰为首，号黑暗魔法界。其土贫瘠，不生五谷。族人多以掠光为业，抢夺东边阳光与沃土为生。其首领头戴红头巾，名曰——'"

她停了一下，念出了那个名字：

"'黑焰'。"

红头巾。黑焰。黑暗魔法界。

小彩小声重复了一遍："黑焰……"

"古籍上还有一段，"小玉继续读，"'黑焰誓立霸王盛宴，以热光为食，以成瘾之味控人心智。盛宴之日，即为东侵之始。'霸王盛宴——和那张碎纸片上的'霸王'对上了。"

紫晶国王的脸色变得非常严肃："也就是说，'三天之后'可能是霸王盛宴的准备时间。三天后他们就要东侵了？"

"古籍上的记载不一定完全准确，"小玉谨慎地提醒，"但所有的线索都指向同一个方向。我们不能忽视。"

**倒计时开始**

小金合上笔记本，深吸了一口气，然后做了一个决定。

"大家听好，"他的声音不大，但每个字都很清楚，"彩虹桥虽然只修好了一半，但至少证明了一件事——我们有力量让光照亮更远的地方。现在，西边的威胁已经不再只是线索和猜测了。"

他看向红隼："继续高空监视，每隔半天报告一次。重点关注黑色移动点的方向和速度。"

他看向紫晶国王："紫晶，请下令加强王国的外围巡逻。地鼠在地下巡查，甲虫在地面巡查。不做防御工事，只做信息收集。"

他看向小玉："请你继续深读古籍，把所有和'黑暗魔法界''霸王盛宴'有关的记载都找出来。"

最后，他看向小彩。

"小彩，"小金蹲下来，平视着弟弟，"接下来可能比我们经历过的所有冒险都难。我不是要你勇敢，我是要你记住这一路上学到的所有东西——观察、控制、诚实、信任。能做到吗？"

小彩用力点了点头。七彩光芒在他周围安静地闪着，不再像刚出生时那样到处乱射，而是稳定、柔和、像一圈小小的彩虹铠甲。

"三天。"小金站起来，看着西边天际线上那层越来越浓的灰幕，"从现在起，我们有三天时间做准备。"

没有人欢呼，也没有人慌张。广场上只响起一阵很轻的吸气声，像是整个王国在同一刻把心收紧了一点。可下一秒，这阵安静就慢慢变成了动作：蚂蚁开始去搬记录板，地鼠转身往地下通道跑，甲虫巡逻队把原本散开的路线重新对齐。倒计时并没有把大家钉在原地，反而像一声无形的铃，让所有人都更清楚自己接下来该做什么。

**远方**

与此同时，在西方那片常年被黑烟笼罩的荒地深处，许多黑玉米正围着一口又一口黑铁大锅忙碌。火焰不是金黄的，而是带着暗红边缘的黑色。苦涩的烟往上翻卷，把头顶本就不亮的天空熏得更沉。

一个头戴红头巾的高大黑玉米站在最高的石台上，正冷冷地盯着东边那道刚修好的七彩光桥。

"彩虹桥果然修好了。"黑焰用手指轻轻敲着锅沿，发出沉闷的"当、当"声，"东边的光……比我想的还要亮。我的'霸王盛宴'，就差最后一道最足的火候。"

他眯起眼睛，看着那道照亮天边的彩虹，嘴角慢慢扬起一个危险的弧度："阳光调料，自己送上门了。"

下一秒，他猛地转身，对着身后那些忙碌的黑玉米大声下令：

"都给我听好了！三天！三天之内，把车、锅、钩索和火器全都准备好！我们去东边——把那里的阳光带回来！"
倒计时一落下，王国里的节奏几乎立刻变了。以前大家讨论的是下一颗宝石在哪里、哪条路更快；现在大家谈的却是风要从哪个方向转、今晚谁守哪一段路、哪些话该先记下来再说。可这种变化并没有把整个王国压得喘不过气，反而让每个人都比平时更安静、更专心。小彩跟着小金去给守夜点分发露珠灯时，看见连最爱打闹的小玉米粒们都自发把声音放低了，好像谁都知道，这不是害怕，而是在给即将到来的三天腾出清楚的脑子。

小玉把古籍搬到广场中央，一边翻一边给大家讲黑暗魔法界的旧记载；紫晶国王则让巡逻队把所有异常现象都记在同一张大板子上，谁看见灰烬飘得更近了、谁闻到焦味更重了，都要写上时间和方向。小金站在板子前，能清楚看见一条从零碎信息慢慢连起来的线。那种感觉很奇怪，既让人心里发沉，又让人不至于乱掉——因为只要线索还在增加，问题就还不是一团只能硬扛的黑雾，而是终究可以被看清、被应对的东西。

就连广场上的风声，都像被这种有条不紊的准备压得沉稳了些。

而这份沉稳，正是小金最想替大家守住的东西。

因为真正的慌乱，往往就从没有准备的空白里长出来。

---

**互动时刻**：

1. **信息拼图**：小金把所有线索（黑羽毛、灰烬之墙、碎纸片、旧册子、红隼的报告）拼在一起，才看清了全貌。你觉得收集信息为什么重要？少一块拼图会怎样？
2. **面对威胁**：小金没有恐慌，而是冷静地分配任务。你觉得"冷静"是天生的还是可以练习的？
3. **准备的力量**：小金给了大家三天准备时间，而不是立刻行动。为什么不马上出发？准备时间有什么用？
4. **悬念预测**：黑焰的"霸王盛宴"到底要做什么？"阳光调料"是什么意思？三天后，小金和黑焰会正面相遇吗？
