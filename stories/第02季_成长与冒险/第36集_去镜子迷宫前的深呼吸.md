# 第36集_去镜子迷宫前的深呼吸

**前情回顾**：棉花糖沙发岛差点把小彩永远"躺"进去——越舒服越不想动，越不动越没力气，沙发正一点点把他吞掉。小金不硬拉，而是一步步教他先动一根脚趾、再抬一条腿，最后小彩像火箭一样弹了出来。他一口气爬上岩石塔，拿到蓝色宝石。六色归位，只剩最后一颗——可前面的颠倒镜子迷宫连小金都说"今晚不进去"，因为它放大的不是力气，而是心里最深的恐惧。

---
**最后一道关**

告别了棉花糖沙发，所有人都知道前方就是最后一道关卡了——颠倒镜子迷宫。七颗宝石已经集齐了六颗，只要通过镜子迷宫拿到最后一颗，彩虹桥就能修复。

可"最后一道"这四个字，有时候比前面所有的关卡加起来还重。

队伍在迷宫入口前的空地上扎营休息。镜子迷宫的入口是一面巨大的、微微弯曲的镜面，映出所有人的倒影——但倒影的表情和真人不太一样。小彩在镜子里看到的自己，嘴角是向下的。

"镜子里的我……在皱眉头。"小彩不安地说。

"正常，"小玉顾问翻着古籍，"这座迷宫会放大的不是声音、不是力气，而是心里的东西。你皱眉，镜子就让你皱得更深。你害怕，镜子就让你更害怕。"

小彩不说话了，七彩光芒暗了下去。

**第一次主动承认**

晚上，小金正在整理笔记准备明天出发，小彩走过来，在他身边坐下。

"哥。"

"嗯？"

小彩沉默了很久，久到小金以为弟弟只是想安静地坐一会儿。

然后小彩开口了，声音很小："我其实很紧张。"

小金放下笔记，认真地看着弟弟。

"不是那种'打怪兽'的紧张，"小彩继续说，双手无意识地揪着身边的草叶，"是那种……怕让所有人失望的紧张。我们走了这么远的路，集了六颗宝石，所有人都指望着最后一颗。如果我在迷宫里犯错了怎么办？如果我又控制不住自己怎么办？如果……"

他的声音越说越小，七彩光芒跟着一明一暗，像是在替他表达那种说不上来的不安。

"如果让你失望了呢。"小金帮他说完了最后一句。

小彩咬着嘴唇，点了一下头。

**小金没有说"别怕"**

小金没有说"别怕"。他也没有说"你一定行的"。他只是静静地坐了一会儿，然后轻声说：

"小彩，你知道迷宫会放大什么吗？"

"心里面的东西。"

"对。那你觉得，迷宫会放大你刚才说的那些担心吗？"

小彩想了一秒，脸色变了："会……如果我心里一直想着'怕让你失望'，镜子就会把这个念头放得很大很大，大到我看不见别的。"

小金点了点头："所以明天进迷宫之前，有一件事比通过迷宫本身更重要——把你心里那个总嫌自己不够好的声音，先按一下暂停。"

"怎么按？"

小金伸出手，掌心朝上，让小彩看着它："你不用变成一个不怕的人。没有人完全不害怕。但你可以试着对自己说一句话。"

"什么话？"

"我可能不完美，但我已经走了很远的路了。"

小彩看着哥哥的掌心，七彩光芒安静地浮在上面，小小的，不耀眼。

"我可能不完美……"他小声跟着念，"但我已经走了很远的路了。"

那句话一出口，小彩自己先怔了一下。它不像“我不怕”那样响亮，也不像“我一定能赢”那样有气势，可说完之后，他胸口那团一直拧着的东西反而松了一点点。原来安慰自己，不一定非要说最厉害的话，也可以只是老老实实地承认：我现在还会紧张，但我已经不是原来的我了。

"而且你一路上做的选择，"小金收回手，认真地看着弟弟，"走大路不抄近道、帮瓢虫解困、承认自己害怕、先问一句再发火——这些不是'差点做到'，而是'真的做到了'。明天镜子会放大你的缺点，但你的优点也同样存在。关键是——"

"关键是不要让那个'嫌自己不够好'的声音，把所有优点都盖住。"小彩接了下去。

**深呼吸**

小金站起来，伸了个懒腰："来，睡觉之前做一件事。"

他带着小彩走到镜子迷宫入口旁边的一块大石头上。从这里能看到整片星空，也能看到迷宫入口那面巨大的镜面在月光下微微发光。

"闭上眼睛，"小金说，"深呼吸三次。每一次呼气的时候，想象自己把一个担心呼出去。"

小彩闭上了眼睛。

第一次深呼吸。呼气的时候，他想着：*怕犯错。*

第二次深呼吸。呼气的时候，他想着：*怕让哥失望。*

第三次深呼吸。呼气的时候，他想着：*怕自己不够好。*

三口浊气吐完，他睁开眼睛。世界还是那个世界，星空还是那片星空，迷宫入口还是那面沉默的镜子。但他感觉胸口轻了一点点。

晚风从镜面上掠过去，带来一丝凉凉的水汽。那面巨大的镜子把月光折成一条一条细长的银线，落在兄弟俩脚边，像一格一格安静发亮的台阶。小彩看着那些银线，忽然觉得明天的迷宫也许不是一张专门抓人的网，而更像一张会把心里声音放大的考卷。题目不会替他作答，但他已经开始知道，自己该先把哪一句话写在最前面。

他又轻轻吸了一口气，这一次没有刻意把什么“呼出去”，只是认真感觉空气穿过胸口时的起伏。紧张还在，可它不再像一团把人推着乱跑的火，而像一只被抱住的、终于肯安静下来的小兽。小彩侧过头看了看哥哥，心里忽然生出一种稳稳的感觉：明天走进迷宫的时候，镜子里就算出现那个最爱挑刺的自己，他也不会再立刻逃开了。

"明天的迷宫，"小金坐到他旁边，肩膀靠着肩膀，"要打碎的不是镜子，而是心里那个总嫌自己不够好的声音。"

"那个声音……其实是我自己。"小彩轻声说。

"对。所以也只有你自己能让它安静下来。"

月亮从云层后面钻出来，把兄弟俩的影子拉得很长。远处，迷宫的镜面折射出一缕银光，像是某种无声的邀请。

小彩看着那道光，心里虽然还有不安，但那个"总嫌自己不够好"的声音，今晚至少安静了一点。

*我可能不完美。但我已经走了很远的路了。*

明天，该走进去了。

营地那晚很安静，安静得连篝火收缩时发出的轻微“噼啪”都格外清楚。小彩抱着膝盖坐了一会儿，忽然主动把这一路上最让他记得的几个瞬间一个个说给哥哥听：第一次收不住光时的慌乱，在风之谷差点被吹跑时的着急，一个人送宝石时走到岔路口的犹豫，还有刚才面对镜子入口时那种明明没开始闯关、心里却已经发酸的压力。每说出一件，小金都没有急着评价，只是替他把那一刻真正学到的东西点出来。于是小彩发现，那些原本让他丢脸、发窘甚至想立刻忘掉的时刻，其实早就悄悄变成了明天能带进迷宫里的工具。

后来小金还带着他做了一个很简单的练习：看着镜面，不评价，只描述。镜子里眉毛皱着，就说“我现在在皱眉”；心跳很快，就说“我现在心跳很快”；手心出汗，就说“我在紧张”。不说“我真没用”，也不说“我必须立刻变勇敢”，只是老老实实把正在发生的事看清楚。练着练着，小彩忽然发现，原来很多让人害怕的东西，一旦被准确说出来，就不会再一下子长得那么巨大。镜子仍旧冷冷地立在那里，可它像已经提前给了小彩一道提示：只有先看见真实的自己，明天的路才不会被夸张的影子带偏。

小彩听完后，轻轻点了点头，像把这道提示悄悄收进了口袋。

这一回，他没有躲开自己的影子。

**互动时刻**：

1. **自我调节**：小彩主动承认"我害怕"，这不是软弱，而是勇气。你有没有过不敢说出口的担心？说出来之后感觉怎么样？
2. **换位思考**：小金说每个人心里都有一个"嫌自己不够好"的声音。你的那个声音会在什么时候出现？你会怎么回应它？
3. **智慧与宽容**：小彩用三次深呼吸把三个担心"呼出去"。你觉得这个方法有用吗？如果下次紧张的时候试一试，会不会有帮助？
4. **悬念预测**：明天小彩就要走进颠倒镜子迷宫了。迷宫会放大他的缺点，你觉得镜子里的他会看到什么？他能不能打败那个"嫌自己不够好"的声音？
