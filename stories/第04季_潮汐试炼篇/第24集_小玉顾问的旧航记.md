# 第24集_小玉顾问的旧航记

上一集中，苇筏在回旋湾差点翻覆以后，小金没有立刻喊着“再试一次”，而是把大家都叫回树皮板前，认认真真做了一场复盘。载重为什么偏、转向为什么晚、近侧暗旋为什么会被漏看、紧急口令为什么会被听错，一条条都被写成了下一次不能再忽略的课。也正因为这场复盘，小金更清楚地看见：真正那条能走远的船，不会只靠胆量造出来，还得有更系统的水路经验和判断方法。于是，他又一次走进了书房，准备向小玉顾问借更老、更稳的答案。

小金去找小玉的时候，小玉正坐在她的书房里——那是王国西北角一个干燥的石缝洞，三面墙都嵌着晾干的叶片，每一片上都密密麻麻写满了字。洞口挂着半片苇叶帘，挡住了风沙，只漏进一缕斜斜的光。

"小玉姐姐，我想问你几件事。"小金在洞口蹲下来。

"进来吧。"小玉挪了挪身子，给他让出一块能坐的地方。

洞里很安静，空气里有一股干草和墨汁混在一起的味道。小金把地图铺在面前，指着铁鱼骨浅滩以南那片空白区域。

"从这里往下，我们还没走过。"小金说，"你之前说过古籍里提到过下游的景象。我现在想知道的不是那些景象是什么，而是——下游的水面有多宽、水流有多快、有没有比回旋湾更难走的地方。"

小玉没有马上回答。她先从身边一堆叶片里翻出一小叠抄录稿——那是她这些年照着原始残页一字一句誊下来的工作叶片，旁边还夹着她自己补上的小注。真正的古籍残页被她压在一片薄木片下面，怕风一吹就碎。她把木片轻轻掀开，又对着抄录稿一片一片地核对，最后停在了一张特别薄的原页上。

"这一片是我最早找到的残页之一，上面的字也是最模糊的。"小玉先点了点原页，又指了指自己誊好的那张抄录稿，"原件快碎了，我平时都看抄下来的这一份。你看这里——'……出湾口，水阔无际，目不能穷对岸。风自西来，推水成浪，浪高及膝……'"

"水阔无际？"小金的眼睛亮了。

"意思是出了芦苇湾以后，水面变得非常大，大到站在一边看不到另一边。"小玉又指向另一行字，"还有这段——'风推水行，浮物随浪，顺者速，逆者止。'"

小金在心里默念了一遍："风推水行……浮物随浪……顺者速，逆者止。"

"这说明什么？"小玉抬头看小金。

小金想了想，慢慢说："风能推水。水上的东西跟着浪走。顺着风的快，逆着风的停。"

"对。"小玉点头，"这段记载不是在描述风景，是在描述一种规律——风可以给水面上的东西提供推力。"

*风。不是撑杆，不是水流，是风。*

小金的心跳快了起来。回旋湾那次翻覆，最大的问题就是没有自己的动力——水流推着走，到了漩涡里就出不来。如果风能推着船走，那方向就不完全取决于水流了。

"古籍里有没有提到过……用什么来接风？"小金问。

小玉翻了翻另一片残页，上面有几个勉强能辨认的字："'……立片于舟，承风而行……'"

"立片于舟。"小金念出来，"把片立在船上，用来接风。"

"我以前读到这段的时候不太确定'片'是什么。"小玉说，"但现在结合前面的记载来看，我觉得'片'就是某种能被风吹动的平面——就像我们拿一片苇叶举在风里，苇叶会被风推着往一边倒。如果把更大的片固定在船上，风吹片，片推船——"

"船就自己动了。"小金接上了。

小玉微微一笑："古籍里的先辈早就知道这件事了。只是他们的记载太零散，我一直没法确认。直到你们在回旋湾翻了筏子，我才把这些片段串起来——因为他们遇到的问题，跟你们遇到的一样。"

"他们也翻了？"

小玉翻了翻另一片残页，上面有一行字："'初试木筏，至湾口翻覆，溺物尽失。后以大片承风，方得过。'"

小金盯着这行字看了很久。

*先辈们也翻过。他们也用筏子试过，也被水流打翻过。后来他们找到了办法——用风。*

"小玉姐姐。"小金抬起头，"你手里这些残页，一共记载了多少下游的情况？"

小玉把那一小叠叶片全部铺开，一片一片地指给他看。

"这里是水面的描述——'阔无际'，说明下游不是窄河道，而是一片很大的开阔水域。"

"这里是水质的描述——'色如铁锈，味苦且涩'，跟我们看到的铁鱼骨渗出的黄水吻合。"

"这里是障碍的描述——'水中有巨骨横卧，旁多碎壳'，应该就是你标的铁鱼骨。"

"这里……"小玉的手停在一行更模糊的字上，皱起了眉，"'……远方有烟柱升腾，日夜不息，其下有硬壳堆积如丘……'这一段我之前给你看过，跟灰屑的来源吻合。"

"还有吗？"

"还有一段，我一直不太确定。"小玉翻到最后一叶，上面的字迹比其他几片更工整，但缺了一角。"这里写的是——'风不止，水不歇。若得其法，可借风云行万里。'"

"借风云行万里……"小金轻声重复。

"我不确定这是写实还是比喻。"小玉说，"'万里'可能是古人的夸张说法。但'风不止，水不歇'这句——意思是外面的风和水一直都在动，不会停下来等你。如果你能掌握利用它们的方法，就能走得很远。"

小金把所有残页的信息在脑子里过了一遍。

水很宽。风一直在吹。可以用"片"来接风。先辈翻过筏子，后来找到了办法。远处还有烟柱和堆积如丘的硬壳。

他站起来，把地图摊在叶片旁边。小玉的古籍残页没有地图，但文字里的方位描述足够让他在地图上标出几个关键点：开阔水域、铁鱼骨位置、烟柱方向。

"小玉姐姐。"小金说，"你能不能把这些残页上所有关于水面、风向和水流的记载整理到一起？不用写故事，只要把每一条的事实列出来就行。"

"你想拿这些做什么？"

"我要拿去给所有人看。"小金说，"之前老灰壳他们反对出去，是因为觉得外面什么都没有、去了白跑。但如果古籍里有记录，下游的水面有多宽、风有多大、先辈是怎么走过去的——那就不是我们瞎冒险，而是有前人的经验在指路。"

小玉看着他，目光里有一种说不清的东西——像是欣慰，又像是心疼。

"好。"她说，"给我两天。"

小金走出石缝洞的时候，天已经快黑了。第一个灯站亮了起来，蓝绿色的光在暮色中柔和地闪烁。

他站在灯站旁边，看了看远处。南边的天际线还是灰蒙蒙的，但今晚的风比前几天多了一点——不多，只是刚好能把他的衣角轻轻吹向一边。

*风一直在。我们只是从来没想过，它不只是天气——也可以是路。*

小金低头在地图上写了一行字："小玉顾问整理中——《旧航记》。待完成后，提交王国大会。"

他把地图收好，转身朝王国走去。风在他身后轻轻推了一把，像是催他快一点。

**互动时刻**：

1. **自我调节：** 小金没有急着造船，而是先去找小玉了解前面的路是什么样。你做事之前，会先收集信息再动手，还是先动手再遇到问题时再想办法？

2. **换位思考：** 小玉这些年一直在独自研究古籍残页，很多内容无法确认，也没有人讨论。如果你是她，突然有人来问你"下游长什么样"，你会是什么心情？

3. **智慧与宽容：** 古籍上写先辈们也翻过筏子，后来才找到用风的方法。这说明失败不是终点，而是找到正确方法之前必须经历的步骤。你有过这样的经历吗？

4. **悬念预测：** 小玉要整理的《旧航记》里，还有一段关于"烟柱"和"硬壳堆积如丘"的记载。如果小金把所有信息拿到王国大会上，老灰壳他们会怎么反应？
