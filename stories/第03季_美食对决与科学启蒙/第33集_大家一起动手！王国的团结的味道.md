# 第33集_大家一起动手！王国的团结的味道

**前情回顾**：小金终于让大家看见，心之筛真正缺的不是稀有食材，而是每个人都肯往前走半步。紫晶国王先让了路，小玉顾问摊开了旧记录，小彩也把自己的暖火石先放去补公共火口，广场中央这才重新升起更稳一点的金色蒸汽。可小金很清楚，这还只是开始——只靠几个人先动，还撑不起整座广场。要想让霸王盛宴真正压下去，王国里更多双手、更多颗心，都得一起动起来。

---

风把黑锅里的苦辣味吹得更远了些，也把小金那句“轮到大家一起加进来了”送进了整片广场。

这一次，没人再觉得那只是说给别人听的话。

最先动的，是刚才抱着两份叶碗不肯松手的小玉米粒。他低头看了看自己怀里的碗，又看了看身后那个比他更小、已经快哭出来的小家伙，咬了咬牙，终于把多抱的那份递了出去。

“这……这份先给你。”他说完，耳朵尖都红了，“我刚才太怕自己分不到了。”

那个小家伙愣愣接过叶碗，连谢谢都慢了半拍。可就在两只小手交过去的那一瞬间，心之筛锅壁上那圈旧金纹路忽然连着亮了三下，像有谁在锅底轻轻拨响了一串小铃。

“又亮了！”守在灶边的小彩立刻喊。

这下，更多人真的看明白了。

原来团结的味道不是谁把漂亮话说得最圆，而是你愿不愿意先把自己怀里那一点抓得太紧的东西，松开一点。

胖乎乎的玉米大叔先挠了挠头，转身去找刚才被自己踩了藤蔓的西瓜伯伯：“刚才是我走太急了。你那根藤我回头帮你扶正，现在先过来一起把后排挪开，别堵着小灶。”

西瓜伯伯本来还板着脸，听见这话也有些不自在地咳了一声：“我也不该只顾着发脾气。行，先搬灶台边那几块挡路的石头。”

两人一胖一高，立刻蹲下来把灶台侧面那堆被踩乱的碎石往两边挪。空出来的那条窄道一通，蚂蚁工程师运暖阳石的队伍就能跑得更稳了。

果然，几只小蚂蚁接力奔过去时，脚步比刚才顺了许多。它们也不再只顾低头赶路，而是有两只主动停下来，把一块偏沉的暖阳石从中途接了过去。

“左边火口弱一点！”

“我们来补！”

灶膛里火舌“呼”地往上一蹿，心之筛里那缕金色蒸汽，也跟着变得更厚了一层。

小金一边搅锅，一边把这些变化全看在眼里。每一份让步、每一份补位、每一份不再只看自己的动作，都会让锅里那股原本还散着的暖意重新聚一点。那不是一下炸开的光，而像一锅本来还偏淡的汤，终于开始慢慢熬出真正的底味。

“大家继续。”他朝四周喊，“不是为了把谁比下去，是为了把已经散开的东西一份份接回来！”

话音刚落，护理棚边的绿叶婶婶就先扶住了两位恢复得慢些的居民。

“你们别挤前头，先坐稳。”她转头又招呼旁边几个年轻些的玉米粒，“谁腿脚快，帮我把热水盆挪到这边来。别等人倒了才想起照顾。”

那几个年轻人原本还在盯着黑锅看，像生怕自己少看一眼就错过什么可怕变化。可这会儿一听，也不再只是站着发慌，赶紧一起去搬热水、挪叶垫、腾位置。护理棚前原本乱糟糟的一片，居然真的被他们一点点理顺了。

心之筛锅里冒出来的金色蒸汽，已经不再只是细线，而像一缕轻软的暖雾，开始沿着灶台上方慢慢铺开。

黑焰脸上的神色终于有点变了。

因为他发现，这些变化和他最怕的一样——没有谁在高台上大喊“我们赢定了”，却越来越多人不再跟着霸王盛宴的气味往乱里走。只要广场上少一个抢位置的人，少一句“先顾我自己”，他的黑锅里那股越煮越旺的霸道味，就像少了一把柴。

他猛地一搅锅，黑汤立刻往外翻，苦辣热浪贴着地面卷过去，专挑最容易乱的地方钻。几个刚缓过来的居民果然又被冲得心口一闷，下意识想把怀里的东西抱紧。

可这一次，还没等那股乱劲真的窜起来，旁边就先有人伸手按住了。

“先别急，我们一起分。”

“你家孩子还小，你先领这一份。”

“我这边还有，别抢。”

那些话不大，却一句接一句，把黑浪想撬开的缝隙又堵了回去。小金听着这些声音，眼底那层紧绷终于松开了薄薄一层。他知道，大家还没有完全稳住，可至少已经开始自己补缝、自己托住彼此了。

这时，广场边缘忽然传来一阵翅膀拍动的响声。

几只小蜜蜂从花田方向飞了过来，尾巴上还沾着清晨采回来的花粉。它们没有像从前那样只顾着把花粉送回蜂巢，而是在半空里绕着灶台飞了一圈，把最甜、最暖的那层香气轻轻抖进锅边的热气里。

“这是今天最先开的向阳花花粉！”领头的小蜜蜂脆声喊，“不能光让你们在地上忙，我们也出一份力！”

紧接着，守在地下热道口的光明地鼠们也齐声应了一句：“地热再往上送一格！”

整口锅下的火，顿时比刚才更稳、更匀。心之筛里的水面轻轻一颤，竟真的析出一股更完整的香气。

那香气不是特别浓烈，也不抢鼻子。它更像冬天傍晚从家门缝里先钻出来的那口热饭香，像你摔了一跤时有人先把手伸过来、什么都没问就把你拉起的感觉。它一飘开，广场上很多人胸口那点一直绷着的硬气，就自己先松了一分。

“这就是……”小彩吸了吸鼻子，眼睛慢慢亮起来，“团结的味道？”

“还在成形。”小金轻声回答，可声音里已经有了更稳的把握。

因为他看见，锅里的力量不再只来自一两个人，而是开始从广场各个方向一丝一丝汇过来。有人在前头分汤，有人在后头让路；有人补火，有人照看孩子；有人扶住老人，有人提醒自己别再被那股“先顾自己”的坏味道带走。那些动作单看都不惊天动地，可一旦全放进同一口锅里，就慢慢熬出了真正能把大家再拢回来的底味。

就连黑焰那边，也终于有人动了。

小炭站在锅架旁，手里还攥着那把添料用的小木勺。她看着广场上这一切，胸口起起伏伏了好一阵，最后忽然走出半步，把刚分到手里、却一直舍不得吃的那小撮暖盐递给了小豆。

“你拿去。”她压低声音，“不是给首领那锅，是给那边公共锅边上那碗热水。你刚才不是说，有几个孩子被烟呛得一直咳吗？”

小豆愣了愣，随即重重点头，抱着暖盐就往护理棚那边跑。

那一刻，小金分明看见，心之筛上的金色蒸汽又往外铺开了一小圈。

这下，连原本还在观望的人也终于不再只站着了。

一个接一个，一排接一排，大家都开始忙自己眼前最该做的那件小事。有人把藏起来的甜粒倒进公碗，有人把歪掉的分粮牌重新插正，有人主动去替守夜队补位，让已经守了大半夜的人先歇口气。半空里的飞鸟不再只盘旋惊叫，而是低飞着把黑雾往空处扇；草叶间的甲虫把翻倒的小木桶重新顶正；连最小的瓢虫也在灶边来回跑，替大伙儿传“这边还缺一盆热水”“那边再让一条路”的消息。

向日葵广场从来没有像现在这样，同时被这么多看似细小、却都朝着同一个方向的动作撑起来过。

心之筛终于发出一声又长又稳的低鸣。

那股暖香不再只是锅边一小圈，而是和金色蒸汽一起，慢慢往整片广场上空铺开。最靠近霸王盛宴的那层黑气，终于被它真正压得往后一退。很多刚才还觉得胸口发堵的人，都像一下能顺畅地吸进第一口完整的空气。

“压住了！”有人惊喜地喊。

“真的压住了！”

可小金没有像旁人那样只顾着高兴。他在那股逐渐成形的暖香里，还闻见了一点更沉、更拧、更不甘心散掉的东西。

那是被心之筛从霸王盛宴里一层层筛出来的贪婪、嫉妒和怕失去。它们没有再像刚才那样散着乱扑，而是在金色蒸汽越压越稳之后，被逼得往高处一点点拧成团，像一团不愿承认自己已经被看穿的黑泥。

最先看见这个变化的，是小玉顾问。

“小金，”她望着半空那团开始往里缩的黑影，声音压得很低，“它们没有消失。”

小金也抬头看见了。

那团黑影还不算大，却正在霸王盛宴上方慢慢聚拢。它像许多被筛出来的坏念头终于找到了彼此，边缘一会儿鼓起，一会儿又往内塌，仿佛正憋着要长成什么更吓人的样子。

风吹过广场时，团结的味道仍旧暖暖地托着大家的心，可更高一点的地方，已经有另一种终局的影子，开始在黑锅上空悄悄找形状了。

**互动时刻**：

1. **自我调节**：故事里真正让团结的味道变浓的，不是一下做成大事，而是很多人先把自己那一点“抓太紧”的劲松开。你觉得自己在着急或害怕时，最先可以松开的，会是哪一点呢？
2. **换位思考**：如果你是小炭，看着广场上的大家一点点一起动手，你会不会也想从黑锅那边走出来，做一点不一样的事？为什么？
3. **智慧与宽容**：小金一直提醒大家，先做眼前最该做的小事。为什么面对很大的危机时，“先扶住一个人、先让开一条路”这种小动作，反而最能把局面救回来？
4. **悬念预测**：现在团结的味道已经开始真正压住霸王盛宴了，可那些被筛出来的坏情绪却在半空慢慢拧成了黑影。你猜，它们接下来会变成什么样子？
