## 📖 项目简介

**《小玉米粒王国英雄小金》** 是一部融合**微观自然科普、儿童心理成长与硬核科幻**的原创长篇故事集。全系列共 **440 集**（约 160 万字），横跨 **十一季**，从一颗玉米粒的求生史诗，写到整个宇宙的共鸣与传承。

### 故事的起点

2025 年 10 月一个寻常的夜晚，两个孩子——**皮皮**与**元宵**——缠着要听睡前故事。于是我随口编了一颗小玉米粒的冒险。没想到他们越听越入迷，第二天又来催，第三天还在问："小金后来怎么样了？"

就这样，一个睡前故事生了根，慢慢长出枝桠，长成了一整片森林。

### 核心特色

| 特色 | 说明 |
| :--- | :--- |
| **微观视角** | 在玉米粒的尺度下，露珠是放大镜，雨滴是炸弹，人类的垃圾是未解的"古代遗迹" |
| **双线叙事** | 小金的"理性建设"与小彩的"感性探索"两条成长路线并行，殊途同归 |
| **科学启蒙** | 从观察推理到实验验证，将科学思维自然融入冒险叙事 |
| **心理成长** | 每集末尾设置互动问答，引导儿童思考情绪管理、同理心与边界感 |
| **宏大世界观** | 从玉米田到银河系，十一季完成从微观求生到宇宙守护的认知跃迁 |

## 📜 故事概要

这是一个关于**两位英雄**的故事。

**小金**是一颗拥有重生后双重视角的小玉米粒。他以发明家的好奇心与科学家的严谨，带领族人从一片小小的玉米田出发——化解病虫害危机，对抗伪科学的侵蚀，感化昔日的敌人，建造飞船驶向星空，最终在宇宙的尺度上守护生命、传承记忆、学会放手。

**小彩**是远古彩虹族的后裔，由三色玉米粒组成。他从一个控制不住光芒的急性子，成长为银河间的星光守护者——穿越宇宙收集七十七颗生命种子，与寂静者对话实现生命与静止的共存，最终创造"未来之种"，把守护精神传递给新一代。

这不是一个普通的童话。它是一场关于**成长**的史诗：从"用露珠做放大镜"的微观智慧，到"用逻辑门重启巨型机器"的宏观科技；从一颗种子的求生，到整个宇宙的共鸣。每一季都是一次认知的跃迁，每一集都藏着一个值得思考的问题。

## 🧭 双重成长路径 (Two Life Paths)

故事中设计了两条截然不同但同样精彩的人生路线。每个孩子都能在小金或小彩身上看见自己的影子——不是非此即彼，而是此刻最需要听到的那种声音。

> 完整的十一季成长轨迹与分季分析，请参阅 [docs/主角成长路线.md](docs/主角成长路线.md)

### 智慧建设者：小金路线 (Xiao Jin's Path)

**成长关键词**：观察 · 逻辑 · 系统 · 理性的力量

从"造工具帮大家解决问题"的发明家，成长为"设计规则让每个人自己站住"的规则设计者，最终成为"把位置、经验与权力真正交出去"的传承者。十一季里，小金始终没有变过一件事——**他最厉害的能力，不是自己有多强，而是他能让身边的人变强**。

### 勇敢探索者：小彩路线 (Xiao Cai's Path)

**成长关键词**：情绪管理 · 同理心 · 边界感 · 成长的重量

从"只会冲"的热血少年，到"学会控制自己为什么而冲"的七彩火焰战士，再到"理解融合的代价"的宇宙守护者，最终成为"把守护精神凝聚成可传递的种子"的传承者。**天赋是起点，不是终点；学会驾驭天赋，比拥有天赋更重要**。

### 殊途同归

两条路线汇于一点：**真正的强大，不是你一个人能做什么，而是你能让多少人因为你的存在而变得更好。**

## 🌍 世界观设定 (World Building)

- **微观物理学**：在玉米粒的视角下，一滴雨水是炸弹，一片树叶是飞船，人类的垃圾是未解的"古代遗迹"。
- **混合科技观**：自然魔法（月亮女神的祝福、彩虹花粉）与远古科技（纳米颗粒、EMP、机械昆虫）并存。
- **生态循环**：所有高科技发明都源自自然材料或人类废弃物，强调"废物利用"。
- **双源力量**：宇宙由"生命"与"寂静"两种本源力量构成，二者同源而异形，共存而非对立。

> 完整设定请参阅 [docs/lore/世界观大纲.md](docs/lore/世界观大纲.md)

## 💝 给父母和孩子们的话 (A Letter to Families)

**给父母们**：小金的路线是"如何通过帮助别人成长来完成自我成长"，小彩的路线是"如何在拥有强大力量的同时学会克制与边界"。两条路线给了我们一个启示——真正的教育不是替孩子把路铺好，而是教他们自己画地图。

**给孩子们**：这个故事，始于你们俩赖在床上不肯睡、非要再听一集故事的那个晚上。小金教你们怎么带着别人一起走，小彩教你们怎么管住自己。不管走哪条路，都要学会温柔地对待这个世界。故事里的英雄写到了第十一季，而你们的故事才刚刚开始。
